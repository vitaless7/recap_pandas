# Análise de Aluguéis com Pandas 🏠📊

Este projeto foi desenvolvido com o objetivo de praticar **manipulação e análise de dados com Pandas**, utilizando um dataset com informações de imóveis para aluguel. A ideia é transformar dados brutos em informações úteis e estruturadas para possíveis aplicações futuras em ciência de dados.

---

## 🧰 Ferramentas Utilizadas

- Python 3
- Pandas
- Jupyter Notebook (ou Google Colab)

---

## 🎯 Objetivos

- Praticar limpeza, transformação e análise exploratória com Pandas.
- Gerar colunas novas a partir de combinações de dados.
- Explorar colunas como tipo de imóvel, bairro, número de quartos e vagas.
- Criar descrições automáticas para os imóveis.

---

## ✨ Principais Etapas

1. **Importação dos dados**  
   Os dados são carregados a partir de um arquivo `.csv` para um DataFrame Pandas.

2. **Análise exploratória inicial**  
   Foram exibidas as primeiras linhas, tipos de dados, valores nulos e estatísticas descritivas.

3. **Criação de novas colunas**  
   - Foi criada uma coluna `Descricao` combinando várias colunas com texto para gerar descrições como:
     > _"Apartamento em Centro com 2 quarto(s) e 1 Vagas de garagem."_

4. **Conversão de tipos**  
   As colunas numéricas foram convertidas para `str` para facilitar a concatenação com strings.

5. **Organização dos dados**  
   Reorganização de colunas, renomeação de headers e limpeza de possíveis inconsistências.
